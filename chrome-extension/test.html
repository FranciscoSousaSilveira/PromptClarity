Prompt Enhancer Test Bench

Use this page to test the loaded unpacked Chrome Extension. To test:

  1. Load this extension folder (chrome-extension/) in chrome://extensions/.
  2. Open this file (test.html) in Chrome.
  3. Focus any field and write a prompt. The suggestion opens automatically after a short pause.
  4. Use Insert Prompt to replace the draft, or Copy to keep the original.
